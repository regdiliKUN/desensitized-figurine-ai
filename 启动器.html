📁 文件 & 环境

打开目录、命令行、环境自检、命令参考。

⚙️ 命令行参考：
python fig.py auto "描述" — 全自动
python fig.py i2i "参考图.png" "提示词" --engine qwen --refs a.png b.png — 图生图（带参考图）
python fig.py edit_image "图.png" "要求" --method local --mask m.png --refs a.png — 局部重绘
python fig.py model 图.png --remesh-res 512 --smooth-iters 3 --faces 0 — 高精度 3D
python fig.py print 模型.glb --model-height 150 --base 0.05 --hollow 0.04 — 打印格式
python fig.py doctor — 环境自检
