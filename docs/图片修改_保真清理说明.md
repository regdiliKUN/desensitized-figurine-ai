# 图片修改：保真清理与整图重生成

适用于非露骨的插画、角色设定图和日式平涂图片。

## 去除骨骼 / 绑定标记（推荐）

1. 在“修改已有图片”里选图，勾选“启用涂抹区域”。
2. 处理方式选择 **“去除标记（保真清理，推荐）”**。
3. 只涂标记本身和极窄的边缘；不要把脚趾、手指、线稿或大块皮肤一起涂进去。
4. 要求可写：`去掉所有青色骨骼绑定点和连线，补回原来的平涂线稿与颜色；脚趾、腿部轮廓和阴影保持清晰。`
5. 速度优先选“快速 · 12 步”；通常选“平衡 · 16 步”；只有确实需要时才选“精修 · 20 步”。方案数保持 1 个最快。

该模式只将模型生成的选区内容贴回原图。选区外的像素保持原样，并且不会使用容易把线稿、脚趾抹平的强无缝融合。

## 整图重生成

“整图重生成（真正重画全图，忽略涂抹）”现在会把**完整原图**传给模型，并要求它返回相同画幅的完整画面；不会再把涂抹区误当成局部裁切。它适合整体改构图或画风，但因为整张图都会由模型重画，不适合只消除几个小标记。

## 为什么不要把两种方式混用

若目标只是去掉局部标记，整图重生成既慢，又会让模型重新解释脚趾、线稿和阴影。使用“保真清理”能得到“原始整图 + 局部高清补回”的结果；若多个区域相距很远，分两三次小范围处理通常比一次把全身涂满更稳定。

内部的局部原始输出不会再显示在最近输出中；界面下方预览和候选才是可使用的完整成品。
