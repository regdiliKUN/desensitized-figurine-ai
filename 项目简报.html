三、如何使用

桌面使用（推荐小白用）

  1. 双击桌面「手办AI」（唯一图标）→ 自动启动 ComfyUI 服务 + 打开控制中心界面
  2. 在界面里选择操作：🚀一键生成 / 🛡️去敏感化 / 📁打开文件夹 / ⌨️命令行
  3. 界面自动检测服务状态（每30秒刷新），绿灯=运行中，红灯=未启动

命令行（高级用户）

# 先启动 ComfyUI 服务
E:\AI\ComfyUI\venv\Scripts\python.exe E:\AI\fig.py serve

# 全自动（中文描述 -> 出图 -> 图生3D -> 打印格式）
E:\AI\ComfyUI\venv\Scripts\python.exe E:\AI\fig.py auto "银发红瞳双马尾少女，水手服，全身立绘"

# 分步操作
E:\AI\ComfyUI\venv\Scripts\python.exe E:\AI\fig.py img "1girl, silver hair, red eyes" --model pony
E:\AI\ComfyUI\venv\Scripts\python.exe E:\AI\fig.py model 出图.png --remesh-res 512 --smooth-iters 3 --faces 0
E:\AI\ComfyUI\venv\Scripts\python.exe E:\AI\fig.py print 模型.glb --model-height 150 --base 0.05 --hollow 0.04

# 环境自检
E:\AI\ComfyUI\venv\Scripts\python.exe E:\AI\fig.py doctor

# 关闭平坦化（测试用）
E:\AI\ComfyUI\venv\Scripts\python.exe E:\AI\fig.py model 出图.png --no-flatten

# ★ 去敏感化（过 Meshy / 建模 AI 审核）
E:\AI\ComfyUI\venv\Scripts\python.exe E:\AI\fig.py desensitize "敏感图.png" --strength auto
E:\AI\ComfyUI\venv\Scripts\python.exe E:\AI\fig.py desensitize "敏感图.png" --strength full   # 全身遮挡（最保守）

# ★ 还原（Meshy 3D → 敏感样子）
E:\AI\ComfyUI\venv\Scripts\python.exe E:\AI\fig.py restore "meshy.glb" --original "敏感图.png"

四、★ 图像去敏感化功能

新增 商业手办工作流：敏感图 → 去敏化 → Meshy 审核 → 3D → 还原

命令用途说明
fig.py desensitize "图.png"去敏感化检测肤色→按区域分级遮挡→输出审核安全版
fig.py desensitize "图.png" --strength full全身遮挡最保守模式，保证过审
fig.py restore "模型.glb" --original "原图.png"还原把去敏化3D还原成敏感样子（需原图参考）

技术细节：

  • 肤色检测：HSV + YCbCr 双判据 + 二次元肤色扩展（浅粉/米白/深色）
  • 区域分级：胸/腰/腹 = 高风险（自动遮挡）；四肢 = 低风险
  • 遮挡方式：服装色覆盖 + 像素化 + 边缘柔化
  • 实测：二次元立绘肤色检测 9.1%，高风险区域 1.3%，auto 模式遮挡 1.3%

四-B、★ 图生图 img2img 功能

新增 参考图 + 提示词 → ComfyUI 重绘，支持 Pony 和 Flux 两种模型

命令用途说明
fig.py i2i "参考图.png" "1girl, swimsuit"图生图以参考图为基础，按提示词重绘（denoise=0.7 默认）
fig.py i2i "图.png" "tags" --strength 0.5轻度重绘保留更多原图细节，适合换色/小改
fig.py i2i "图.png" "tags" --strength 1.0完全重画等同 txt2img，只保留构图

--strength 参数指南：

  • 1.0 = 完全重画（几乎不保留原图）
  • 0.7 = 大幅修改但保留构图（默认推荐）
  • 0.5 = 适度修改，保留大部分细节
  • 0.3 = 轻微调整（换颜色/小细节）

工作流： LoadImage → VAEEncode → KSampler(denoise=strength) → VAEDecode → SaveImage
